# 函数索引维护规则

## 索引文件

`Docs/函数索引.md` 是本项目的权威函数索引，按模块和 owner class 分类记录所有项目自有 .gd 脚本的函数签名。

## 维护规则

1. **修改 .gd 文件后必须同步索引** — 每次添加、删除或修改任何 .gd 脚本中的函数签名、信号声明或枚举定义时，必须在同一 commit 中更新 `Docs/函数索引.md` 对应条目。
2. **新增脚本** — 在索引文档的对应章节追加新类、文件路径、extends 信息和函数表。
3. **删除函数** — 从索引对应表格中移除该行。
4. **优先读索引** — 需要查找某个函数所属类、签名或访问级别时，优先读取 `Docs/函数索引.md` 而非 grep 全代码库。
5. **枚举同步** — 索引末尾有所有关键枚举定义汇总（BossHorseTypes.HorseId、BossPhase、PlayerState 等），修改枚举时必须同步更新。

## 索引覆盖范围

- 全部项目自有 .gd 脚本（当前 58 个），不含 addons/dialogic 第三方插件
- 不含 test/ 目录测试脚本

# 资源索引维护规则

## 索引文件

`Docs/资源调用索引.md` 是项目的权威资源双向索引，记录图像/字体/音效/BGM/Dialogic 资源的所有引用位置。

## 维护规则

1. **修改资源引用后必须同步索引** — 每次在 .gd 或 .tscn 中新增、删除或修改资源路径时，必须在同一 commit 中更新 `Docs/资源调用索引.md` 对应条目。
2. **新增资源** — 在索引文档的对应章节追加新行，标注资源路径、类型和所有引用位置。
3. **替换资源** — 先在索引中定位所有引用点，逐一替换后更新索引。
4. **删除资源** — 确保所有引用已清理后，从索引中删除对应条目。
5. **优先读索引** — 需要查找某资源的所有引用位置时，优先读取 `Docs/资源调用索引.md` 而非 grep 全项目。
