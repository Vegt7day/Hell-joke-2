# 04 - 关键类说明

## 类关系（文字描述）

```text
                    [Autoload / 场景根]
     Dialogic              Game                    DialogicRegistry
        |                    |                              |
        |            owns PlayerStats                      |
        |            (Stats instance)                      |
        |                    |                              |
        +-------- starts timelines ---+                   |
                                       |                   |
                              WorldController              |
                              (Node2D)                     |
                    references teacher, player             |
                    connects Dialogic signals              |
                                       |                   |
                    +------------------+------------------+
                    |                  |                    |
               Teacher            Player/Student     Interactable
            (CharacterBody2D)   (CharacterBody2D)   (Area2D)
                    |                  |                    ^
                    |                  |                    |
              蚊子 bullet           Ink bullet          Teleporter
            (CharacterBody2D)    (CharacterBody2D)    (extends)
```

- **`Stats`**：被 `Game` 持有，也被 `Teacher` 子树中的实例用于 Boss 血条。  
- **`Interactable` / `接触触发`**：与玩家数组注册配合，非继承关系。  
- **`ShangYang`**：由 `Player` 召唤，独立于 `WorldController` 的注册表逻辑。

---

## `Game`（`system/globals/game/game.gd`）

**职责**：自动加载场景根脚本；场景切换（淡变 + `world_states`）、存档读档、持有全局 `PlayerStats`。

**关键成员**：

| 成员 | 说明 |
|------|------|
| `world_states: Dictionary` | 以场景文件基名为键的 `to_dict` 快照 |
| `change_scene(path, params)` | 暂停、淡出、`change_scene_to_file`、恢复状态、`update_player` |
| `SAVE_PATH` | `user://data.sav` |
| `new_game()` / `load_game()` / `save_game()` | 流程入口 |

```gdscript
# 关键方法签名（节选）
func change_scene(path: String, params: Dictionary = {}) -> void:
	# await 链内完成切场景与淡入
	pass

func save_game() -> void:
	pass

func load_game() -> void:
	pass
```

**扩展关系**：`extends Node`，挂载于 `CanvasLayer`（`game.tscn`）。

**改进点**：实现或移除 `params["init"]`；修正 `DialogueRegistryManager` 节点路径。

---

## `Stats`（`system/class/stats.gd`）

**职责**：玩家（或敌人）生命与墨水的数值容器；通过 **setter** 钳制范围并发射变更信号。

**信号**：`health_changed`、`ink_changed`。

**序列化**：

```gdscript
func to_dict() -> Dictionary:
	return { max_health = max_health, health = health, max_ink = max_ink }

func from_dict(dict: Dictionary) -> void:
	max_health = dict.max_health
	health = dict.health
	max_ink = dict.max_ink
```

**注意**：`ink` 的 setter 当前写为 `v = clampi(v, 0, max_ink)`，`max_ink` 为 `float` 时类型与精度行为不符合直觉，建议改为 `clampf` 或统一为 `int` 墨水。

**继承**：`extends Node`，通常置于场景实例中而非 `RefCounted`。

---

## `Student`（`entities/player/student/student.gd`）

**职责**：高机动平台操作（Coyote、跳跃延迟）、墨水消耗射击、与 `Interactable`/`接触触发` 集成、可选输入禁用层。

**关键属性**：`move_speed`、`jump_velocity`、`ink_bullet_scene`、`interacting_with` 等。

**关键方法**：`shoot()`、`take_damage()`、`disable_action()` / `enable_action()`。

**继承**：`class_name Student` → `extends CharacterBody2D`。

---

## `Player`（`entities/player/real player/student.gd`）

**职责**：状态机驱动移动/跳跃/攻击/召唤；`execute_summon()` 生成 `ShangYang`；`get_direction()` 供 `Game.update_player` 使用。

```gdscript
enum PlayerState {
	IDLE, WALK, JUMP_ASCEND, JUMP_FALL,
	ATTACK_START, ATTACK_SHOOT, ATTACK_END, STUNNED,
	SUMMON_START, SUMMON_END
}
```

**继承**：`class_name Player` → `extends CharacterBody2D`。

**与 `Student` 关系**：并行实现，**无共同基类**；长期维护建议提取共享模块（如 `MovementComponent`）减少重复。

---

## `WorldController`（`system/levels/world.gd`）

**职责**：首关流程——注册 Dialogic 角色锚点、启动教师时间线、接收自定义信号解锁移动、启动关卡计时与教师攻击、胜负与结局对话。

**关键方法**：

- `register_characters_globally()`：向 `/root/DialogicRegistry` 注册 `"中学生"`、`"老教师"`。  
- `receive(sig: String)`：处理 Dialogic 发出的逻辑信号。  
- `to_dict()` / `from_dict()`：敌人组持久化。  
- `update_player(position, direction)`：供 `Game` 在切场景后放置玩家。

**继承**：`class_name WorldController` → `extends Node2D`。

---

## `Teacher`（`entities/enemy/teacher/teacher.gd`）

**职责**：计时射击、自动掉血、血条显隐、发射 `蚊子` 子弹。

**信号**：`teacher_time_out`、`health_depleted`、`student_intro_triggered`。

**继承**：`extends CharacterBody2D`（无 `class_name`，可通过场景路径引用）。

---

## `Ink` 与「蚊子」子弹

| 类/脚本 | 文件 | 职责 |
|---------|------|------|
| 墨水弹 | `entities/player/bullet/ink.gd` | `move_and_collide`，命中 `take_damage` |
| 蚊子弹 | `entities/enemy/bullet/蚊子.gd` | 可选附着，持续伤害，计时销毁 |

**初始化示例**：

```gdscript
# ink.gd
func initialize(start_position: Vector2, shoot_direction: bool):
	global_position = start_position
	facing_right = shoot_direction
```

---

## `ShangYang`（`entities/npc/商鞅/商鞅.gd`）

**职责**：剧情形态切换动画与召唤模式下受击、阈值触发动画、死亡销毁。

**枚举**：`MODE { SUMMONED, STORY }`、`STATE { IDLE, DAMAGED, TRANSITION, DEAD, COMMON }`。

**继承**：`class_name ShangYang` → `extends CharacterBody2D`。

---

## `Interactable` / `Teleporter` / `接触触发`

```gdscript
# system/可交互物/interactable.gd
class_name Interactable
extends Area2D

signal interacted

func interact() -> void:
	interacted.emit()
```

- **`Teleporter`**：`interact()` 内调用 `Game.change_scene`。  
- **`接触触发`**：`class_name 接触触发`，`interact()` 发本地 `interacted` signal；中文类名在 GDScript 合法但对外部工具链可能不友好。

---

## `DialogicRegistry`（`system/dialogic/dialogic_registry.gd`）

**职责**：`character_id` → `NodePath` 映射，供 Dialogic 布局定位立绘/气泡锚点；`save_registry` / `load_registry` 支持存档（需与 `Game` 路径修复配合）。

**继承**：`extends Node`（自动加载）。

---

## `到区域触发对话`（`system/dialogic/到区域触发对话.gd`）

**职责**：`Area2D` 进入触发 Dialogic；支持 `one_shot`、`require_input`；将对话节点挂到 `current_scene`。

---

## `StatusPanel` / `BossHealthBar`

- **`StatusPanel`**：监听全局 `Game.player_stats`。  
- **`BossHealthBar`**：监听任意注入的 `Stats`，带重试初始化与 `show_health_bar` / `hide_health_bar`。

---

## 继承与扩展关系小结

| 类型 | 父类 |
|------|------|
| Student / Player / Teacher / ShangYang / Ink / 蚊子 | `CharacterBody2D` |
| Interactable / 接触触发 / 到区域触发对话 | `Area2D` |
| Game / Stats / DialogicRegistry | `Node` |
| Teleporter | `Interactable` → `Area2D` |

新增关卡建议：**继承或组合** `WorldController` 模式（同一脚本基类 + 不同导出参数），比复制 `world.gd` 更易维护。
