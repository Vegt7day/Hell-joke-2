# World3 Boss 马战 — 明日任务清单与目标点扣血方案

本文档由 `Docs/12-World3-Boss马战开发日志.md` 中的维护项与「由我补充」整理而成，并写入**已定稿的设计决议**，便于明天直接开工。与设计对照见 `Docs/11-World3-Boss马战设计.md`。

## 一、设计决议（已定）

### 1.1 血量与阶段

- **目标点累计扣血**：通过关卡内**可交互目标**（解密 / 跑酷终点等）触发，每次成功交互后，用**动画表现**扣除 Boss **20% 最大生命值**（或等价：使共享血条下降一档 20% 区间）。
- **阶段切换**：仍按**当前工程已有逻辑**——**每损失约 20% 血量切换一个阶段**（80% / 60% / 40% / 20% 等阈值与现有 `PhaseController` 一致）；目标点扣血与受击扣血**叠加在同一共享血条**上，不因「目标点」另开一套阶段机。
- **明天最小交付**：加入**一个**可交互物品；操作成功后播放约定动画，并调用与现有 `apply_shared_damage()`（或等价单次大额伤害）一致的入口，使 Boss **一次性掉 20%**，从而自然触发若阈值跨越时的阶段切换。

### 1.2 墨水

- **墨水对 Boss（本战）不造成伤害**：直接不结算伤害（例如在 `take_damage` / 投射物碰撞层或 Boss 侧 `can_take_ink_damage` 等处统一关闭），与是否处于解密阶段无关。

### 1.3 与后续扩展的关系

- 未来可扩展为多个目标点，每个目标点同样扣 20%；需避免与「同一帧多次触发」叠层；首版一个交互物即可验证管线。
- 背景、UI 重写、全量音效等仍按下方任务清单分优先级推进，不与本节的「明天一条交互链」强绑定。

## 二、明天任务清单（建议执行顺序）

### P0 — 与 Boss 战管线直接相关

1. **可交互目标 + 动画扣 20% 血（核心）**  
   - 场景中放置**一个**可交互节点（Area2D / 机关 / 检查点等，与项目现有交互方式一致）。  
   - 交互成功 → 播放**扣血动画**（可先占位：Tween / AnimationPlayer / 简单 UI 闪白）。  
   - 动画结束或关键帧调用现有共享扣血接口，**单次扣除 20% 最大生命**，并确认阶段日志 / 换马逻辑与现在一致。  
   - 验收：交互前后血条差约 20%；若从 85% 扣到 65%，应出现与现网一致的跨阈值行为。

2. **墨水对 Boss 零伤害**  
   - 在墨水命中或 Boss 承伤统一入口处关闭对 World3 Boss 的伤害（或本关卡专用分组）。  
   - 验收：持续用墨水攻击 Boss，血量与阶段不因墨水变化。

3. **20% 预警与 UI**  
   - 预警**文字动画**（或等价呈现）；灰色掩膜**去掉或减淡**。  
   - 涉及：`world3_boss_arena` 内 `UIHints` 及致命预警相关 UI。

4. **音效第一批**  
   - 马跳跃、马攻击、商鞅被扯开等事件挂音效；对照 `Docs/10-音频总线配置建议.md` 走查总线。

5. **工程核对（穿插）**  
   - **即死**与 `Game` / 玩家死亡流程对齐。  
   - **World2 商鞅存档键**与 World3 演出衔接核对。

### P1 — 体验与场景

6. **玩家操作手感**：加速度、攻击与移动状态机在 `student.gd` 等处的**小步迭代**（建议单日 1～2 处可量化改动）。  
7. **背景与地板**：马场 / 草地 / 刑场方向选一版，占位进场景。
