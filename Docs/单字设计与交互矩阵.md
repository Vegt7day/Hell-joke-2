# 单字设计与交互矩阵

> 文字地狱重制版 | 最后更新：2026-05-04

---

## 一、道具体系总览

所有道具分为两大类：

| 类型 | 代号 | 墨水消耗 | 使用次数 | 特点 |
|------|------|----------|----------|------|
| **消耗型** | CONSUMABLE | **不消耗** | 用完即无（堆叠数=总次数） | 一次性投入，立即生效 |
| **耐久型** | DURABLE | **每次消耗** | 无限次（或有耐久上限） | 可重复使用，每次消耗墨水 |

**设计逻辑**：
- 消耗型道具是"储备资源"，用完就没了，获取途径有限，**不消耗墨水**
- **玩家专属耐久型**：冲、墨、守，是玩家的常驻能力，每次使用**消耗墨水**，有冷却
- 两种类型共存，玩家需要在"省着用消耗品"和"保留墨水应对突发"之间做权衡

> **注意**：除玩家专属的冲、墨、守外，其余所有召唤/强化/建造/反应道具均为**一次性消耗型**。

## 二、元素系统

原「反应类」改名为「元素类」。召唤出元素字后，字体会粒子化，产生对应的物理粒子效果。

### 2.1 元素粒子总览

| 元素 | 粒子类型 | 受重力 | 受风力 | 特殊物理 |
|------|----------|--------|--------|----------|
| 火 | 燃烧粒子 | 否 | 是 | 向上飘散，附着可燃物 |
| 风 | 气流粒子 | 否 | 否（自身即风） | 朝施放方向吹送 |
| 雷 | 电弧粒子 | 否 | 否 | 快速飞行，自动导电链 |
| 酸 | 腐蚀液体 | 是 | 是 | 流淌、摊开，有残留 |
| 油 | 可燃液体 | 是 | 是 | 流淌、摊开，增强燃烧 |
| 水 | 液体 | 是 | 是 | 流淌、摊开，熄灭燃烧 |
| 冰 | 冰晶粒子 | 否 | 是 | 冻结目标，形成冰面 |
| 暗 | 诅咒粒子 | 否 | 是 | 附着目标，持续减益 |

### 2.2 火 — 点燃

**机制**：召唤「火」字 → 生成燃烧粒子 → 粒子附着附近物体

**效果**：
- 点燃附近的**可燃物品**（标记为 `FLAMMABLE`）
- 点燃附近的**可燃敌人**（标记为 `FLAMMABLE`）
- 点燃**玩家自己**和**召唤物**（双刃剑特性）
- 被点燃的目标每秒受到持续伤害，直到被水熄灭或燃烧时间结束
- 燃烧可以扩散到相邻的可燃物

**标签依赖**：
- `FLAMMABLE`：可被点燃
- `BURNING`：正在燃烧

### 2.3 风 — 吹送

**机制**：召唤「风」字 → 生成气流粒子 → 朝施放方向吹送

**效果**：
- 吹动**可被吹动的粒子**（火/酸/油/水/冰/暗粒子均可被风吹）
- 吹动**可被吹动的召唤物**、**敌人**、**玩家**
- 吹力根据目标**重量**决定：重量越轻，吹得越远；重量越大，吹得越近
- 风可以推散聚集的粒子（如吹散水面/酸面/油面）

**重量分级**：

| 重量级 | 示例 | 吹动距离 |
|--------|------|----------|
| 轻（0-5kg） | 粒子、小型召唤物 | 6-8格 |
| 中（5-20kg） | 普通敌人、玩家 | 3-5格 |
| 重（20kg+） | 大型敌人、重型召唤物 | 1-2格 |

### 2.4 雷 — 导电

**机制**：召唤「雷」字 → 生成电弧粒子 → **快速飞行**向最近的可攻击目标

**目标优先级**：
1. **易被雷击**的目标（标记为 `LIGHTNING_ROD`）— 优先级最高
2. **可被雷击**的目标（标记为 `LIGHTNING_CONDUCTIVE`）— 次优先级

**导电链规则**：
- 雷击中第一个目标后，**自动传导**给附近的「易被雷击」对象
- 传导链**只在「易被雷击」对象之间传递**
- 被传导过的对象**不再作为传导源**（防止无限循环）
- 如果附近**只有**「可被雷击」对象，雷才选择最近的「可被雷击」对象
- 传导链最多延伸 **10格** 距离

**「易被雷击」标签获取途径**：
- 被**水**打湿的目标自动获得 `LIGHTNING_ROD`
- 某些建造物（铁类）天生具有 `LIGHTNING_ROD`

### 2.5 酸 — 腐蚀

**机制**：召唤「酸」字 → 生成酸液粒子 → **受重力影响**，流淌到碰撞体上并摊开

**效果**：
- 粒子接触**可被腐蚀**目标（`CORRODIBLE`）→ **腐蚀并残留**，5秒后目标**消失**
- 粒子接触**不可被腐蚀**目标 → **残留 10秒** 并缓慢消耗（降解）
- **残留期间**：对接触该残留粒子的对象造成持续伤害
- 残留的粒子被接触后**快速被消耗**

**密度**：酸 > 水 > 油（酸最重）

### 2.6 油 — 燃烧强化

**机制**：召唤「油」字 → 生成油液粒子 → **受重力影响**，流淌并摊开

**效果**：
- 对接触到的事物施加**强化燃烧**效果
- `FLAMMABLE` → `HIGHLY_FLAMMABLE`（燃烧更久、伤害更高）
- 无标签 → `FLAMMABLE`（变为可燃）

**移动影响**（对玩家、召唤物、敌人均生效）：
- 最高移动速度**大幅增加**（+50%）
- 与移动方向相反的加速度（刹车/减速）**大幅减少**（-60%）
- 跳跃高度**大幅减少**（-50%）
- 本质：油面极滑，速度快但刹不住，跳不起来

**密度**：油 < 水 < 酸（油最轻）

### 2.7 水 — 熄灭

**机制**：召唤「水」字 → 生成水粒子 → **受重力影响**，流淌并摊开

**效果**：
- `HIGHLY_FLAMMABLE` → `FLAMMABLE`
- `FLAMMABLE` → 不可燃（移除标签）
- `BURNING` → 熄灭火焰
- 被水打湿 → `WET` 标签 → 自动获得 `LIGHTNING_ROD`（易被雷击）

**移动影响**（对玩家、召唤物、敌人均生效）：
- 最高移动速度**增加**（+20%）
- 与移动方向相反的加速度**变少**（-35%）
- 跳跃高度**大幅减少**（-60%）
- 本质：水面湿滑，容易滑行但起跳困难

**密度**：油 < 水 < 酸（水比油重）

### 2.8 元素不互溶规则

酸、油、水三种液体**不互相溶解**，按密度分层：

```
密度排序（从轻到重）：油 < 水 < 酸

同时存在时的分层：
  ┌─────────┐
  │   油    │  ← 最上层
  ├─────────┤
  │   水    │  ← 中间层
  ├─────────┤
  │   酸    │  ← 最下层
  └─────────┘
```

- 同类液体可以融合（水+水=更多水，可扩大覆盖面积）
- 不同类液体接触时不混合，按密度分层
- 风可以吹散液体表面层（从最上层开始）

### 2.9 粒子可吹动性

| 元素粒子 | 可被风吹动 | 说明 |
|----------|------------|------|
| 火 | 是 | 吹动后火势扩散 |
| 风 | 否 | 自身即风，不受其他风影响 |
| 雷 | 否 | 电弧瞬间到达，不参与物理模拟 |
| 酸 | 是 | 风可吹散酸液覆盖范围 |
| 油 | 是 | 风可吹散油面 |
| 水 | 是 | 风可吹散水面 |

## 三、召唤类单字

### 3.1 召唤物通用规则

- 召唤物与敌人共享巡线与攻击机制（AI寻路、攻击判定）
- 当前实现只负责把对象召唤出来，后续复用敌人AI系统
- 召唤物有持续时间，到时自动消失
- 同时最多存在 **3** 个召唤物，超出时最早的自动消失

### 3.2 耐久型召唤（每次消耗墨水，可重复使用）

| 单字 | 名称 | 墨水 | 行为 | 特殊效果 |
|------|------|------|------|----------|
| 商 | 商鞅 | 2 | 自动寻路移动向敌人并产生碰撞效果 | 已实现，嘲讽吸引仇恨 |
| 哈 | 哈基米 | 1 | 自动寻路攻击最近敌人 | 攻击附带**流血**（持续百分比伤害） |
| 牢 | 牢大 | 2 | 自动寻路肘击最近敌人 | 攻击附带**眩晕**（敌人短暂无法移动） |

### 3.3 召唤物状态效果

| 单字 | 状态效果 | 效果描述 | 持续时间 |
|------|----------|----------|----------|
| 裂 | 裂开 | 每秒造成目标最大生命值 X% 的伤害 | 持续到时间结束或被水清洗 |
| 晕 | 眩晕 | 目标无法移动和攻击 | 2-3秒 |

## 四、法术类单字

### 4.1 法术通用规则

- 法术使用后，在**范围内**对所有对象（玩家、召唤物、敌人）生效
- 法术为**一次性消耗型**，用完即无，不消耗墨水
- 法术效果持续一定时间，期间对象持续受影响
- 法术效果为范围生效，无需单独选择目标

### 4.2 法术单字

| 单字 | 名称 | 墨水 | 范围 | 效果描述 |
|------|------|------|------|----------|
| 盲 | 致盲 | 1 | 3格 | 玩家视野受阻；召唤物和敌人索敌范围减少 |
| 疾 | 疾速 | 1 | 3格 | 范围内所有对象加速 |
| 浮 | 浮空 | 2 | 2格 | 范围内对象不受控制地垂直起飞，无法左右移动；效果结束后可在空中自由移动 |
| 缠 | 束缚 | 2 | 2格 | 范围内对象不能移动；不受远程伤害；仍受元素伤害、近战伤害、强化燃烧效果 |
| 祭 | 献祭 | 3 | 2格 | 抽取范围内对象生命（对友方/自己造成双倍伤害，不会致死）；对玩家生成等量临时生命（每2秒减1HP） |
| 睡 | 催眠 | 2 | 2格 | 有睡眠抗性的对象减速50%；召唤物和敌人进入睡眠状态；睡眠中缓慢回血（包括有抗性的）；受击退出睡眠 |
| 吸 | 吸引 | 2 | 3格 | 按对象重量朝中心产生瞬间吸力；对粒子的效果视为时间更短的风 |

### 4.3 法术效果详解

#### 盲（致盲）

**效果**：
- 对**玩家**：视野受阻（暗化屏幕边缘或完全黑屏，仅保留小范围可视区域）
- 对**召唤物**：索敌范围减少 50%
- 对**敌人**：索敌范围减少 50%，攻击精度降低

#### 疾（加速）

**效果**：
- 范围内所有对象移动速度增加
- 不区分敌我，全部加速

#### 浮（浮空）

**效果**：
- 范围内对象不受控制地垂直起飞
- 飞行期间**无法左右移动**（仅受重力和风力影响）
- 效果结束后：对象在空中，可自由移动（有空中移动能力）
- 对粒子的效果：吹散/推向上方

#### 缠（束缚）

**效果**：
- 范围内对象**不能移动**
- **不受远程伤害**（子弹、投射物穿过）
- **仍受**元素伤害、近战伤害、强化燃烧效果
- 可被风力打破束缚（风可以吹散缠绕粒子）

#### 祭（献祭）

**效果**：
- 抽取范围内对象的生命值
- **对友方和自己**：造成双倍伤害
- **对敌人**：造成正常伤害
- **不会致死**：最低保留 1HP
- 对玩家生成**等量临时生命**：
  - 临时生命可以抵挡伤害
  - 每 2 秒自动减少 1HP
  - 临时生命归零时消失

#### 睡（催眠）

**效果**：
- 有**睡眠抗性**的对象：减速 50%（而非完全睡着）
- **召唤物和敌人**：进入睡眠状态
- 睡眠期间：**缓慢回血**（包括有睡眠抗性的对象）
- **受击退出睡眠**：被攻击时立即醒来

#### 吸（吸引）

**效果**：
- 按对象**重量**朝中心产生瞬间吸力
- 轻量对象被吸得更远，重量对象被吸得更近
- 对**粒子**的效果：视为时间更短的风（快速吹向中心）

**重量分级**（与风相同）：
| 重量级 | 吸力效果 |
|--------|----------|
| 轻（0-5kg） | 被吸到中心附近 |
| 中（5-20kg） | 被吸移动3-5格 |
| 重（20kg+） | 被吸移动1-2格 |

## 五、元素交互详解

### 4.1 风 × 火 = 火势扩散

```
风吹过燃烧的粒子/目标 → 火粒子被吹向风的方向
→ 火粒子落在可燃物上时点燃该物
→ 火势随风扩散，覆盖更大范围
```

**战术应用**：「风」+「火」组合可以快速清场

### 4.2 风 × 酸/油/水 = 液面推散

```
风接触液面粒子 → 液体被吹散
→ 液面覆盖范围改变（向风向扩散）
→ 从最上层（油）开始被吹散
```

**战术应用**：用风控制液体分布，或将液体吹向特定方向

### 4.3 水 × 火 = 熄灭

```
水粒子接触燃烧目标 → 熄灭火焰
→ HIGHLY_FLAMMABLE → FLAMMABLE
→ FLAMMABLE → 不可燃（移除标签）
→ 水蒸发消失
```

### 4.4 水 × 雷 = 易被雷击

```
水打湿目标 → WET 标签 → 自动获得 LIGHTNING_ROD
→ 雷会优先传导给 WET 目标
```

**战术应用**：先用水打湿一群敌人，再用雷触发大范围导电链

### 4.5 油 × 火 = 强化燃烧

```
油粒子接触可燃物 → 可燃物升级
→ FLAMMABLE → HIGHLY_FLAMMABLE（燃烧更久、伤害更高）
→ 无标签 → FLAMMABLE（变为可燃）
```

**战术应用**：用油铺路再点火，形成高伤害燃烧带

### 4.6 酸 × 可腐蚀目标 = 腐蚀消失

```
酸粒子接触 CORRODIBLE 目标 → 酸残留
→ 5秒后目标消失
→ 残留期间接触酸粒子的对象受到持续伤害
→ 粒子被消耗
```

### 4.7 油 + 水 + 酸 = 密度分层

```
三种液体同时存在 → 按密度自动分层
→ 最上层：油（密度最低）
→ 中间层：水
→ 最下层：酸（密度最高）
→ 风只能从最上层开始吹散
```

### 4.8 雷 × WET 目标 = 导电链

```
雷击中 WET 目标 → 触发导电链
→ 传导给附近的 LIGHTNING_ROD 目标
→ 被传导过的对象不再传递
→ 传导链最多延伸 10 格
→ 伤害随距离衰减（1格=100%，2格=60%，3格=30%）
```

## 五、标签体系

| 标签 | 说明 | 获取方式 | 移除方式 |
|------|------|----------|----------|
| `FLAMMABLE` | 可被点燃 | 建造物/敌人默认属性 | 被水浇灭 |
| `HIGHLY_FLAMMABLE` | 易燃（燃烧更久） | 被油覆盖 | 被水浇灭 |
| `BURNING` | 正在燃烧 | 被火点燃 | 水熄灭/时间到 |
| `WET` | 被水打湿 | 被水粒子接触 | 蒸发/时间到 |
| `LIGHTNING_ROD` | 易被雷击 | WET标签自动赋予/天生属性 | WET消失 |
| `LIGHTNING_CONDUCTIVE` | 可被雷击 | 天生属性（默认大多数） | — |
| `CORRODIBLE` | 可被腐蚀 | 天生属性 | — |
| `CORRODING` | 正在被腐蚀 | 酸残留 | 酸消失/目标消失 |
| `OILED` | 被油覆盖 | 油粒子接触 | 水冲洗/时间到 |

## 六、交互优先级

| 优先级 | 效果类型 | 说明 |
|--------|----------|------|
| 1 (最高) | 眩晕 | 任何眩晕效果立即生效 |
| 2 | 冻结 | 冻结覆盖其他移动效果 |
| 3 | 致死伤害 | 伤害导致死亡时，其他效果取消 |
| 4 | 持续伤害 | 流血/燃烧等按时间触发 |
| 5 | 状态变化 | 脆弱/减速等持续效果 |
| 6 (最低) | 增益效果 | 攻击力/移速加成等 |

**覆盖规则**：
- 同类型效果取最强值
- 不同类型效果可叠加
- 正负效果可抵消

## 七、交互触发条件

| 触发方式 | 说明 | 示例 |
|----------|------|------|
| **碰撞触发** | 两个实体物理接触 | 火球碰到木墙 |
| **范围触发** | 一个实体在另一个的范围内 | 风吹过燃烧区域 |
| **状态触发** | 一个实体有特定状态时触发 | 流血的敌人被攻击时扩散 |
| **时间触发** | 状态持续时间到期时 | 燃烧的木材5秒后变为灰烬 |
| **组合触发** | 多个实体同时存在时 | 火+风同时存在时触发火势扩散 |
