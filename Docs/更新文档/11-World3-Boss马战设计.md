# World3 Boss 战设计：主马「马」与「驷」及四马

本文档描述 World3 中该 Boss 战的**功能需求、流程、对象划分与实现思路**。四马技能、召唤物动画与主马技能规则已按当前策划填写同步进本文档；工程内若尚无对应脚本/场景，实现时以本节为验收对照。

---

## 1. 设计目标与范围

- **演出**：入场大主 Boss「马」+「驷」；动画后驷变为四马（红 / 灰 / 白 / 黑），贴图与动画已就绪；四马共用同一对象实现（四套贴图/动画在同一资源或同一场景实例中切换）。
- **流程**：主马留在场地；驷化四马后**暂时离场**；按血量阈值依次**单马进场**与主马**技能解锁**联动；20% 血触发**商鞅防御分支**与**五马锁链过场**；过场后**五马同时出场**围攻主角。
- **战斗**：主马与四马各有 `jump`（向前跳）；主马体型不同故**跳跃高度与四马不同**；主马平时一种颜色/状态，释放某马技能前播**切色动画**，技能结束后再播切回，恢复**常态 jump 动画**。
- **道具 / 召唤物**：伸向商鞅的**绳子**；白马**「剑」远程攻击物**；红马**地面炸弹**（见第 7 节动画与判定约定）。
- **四马技能**：已定义灰 / 白 / 黑 / 红四马技能与动画流程（见第 8 节）；主马技能池与共享 CD 见第 8 节末。

## 2. 场景与对象清单（6 个 Boss 相关对象）

| 序号 | 对象名（建议） | 职责简述 | 备注 |
|------|----------------|----------|------|
| 1 | 主马（大「马」） | 整场核心受击体；留在原位；随阶段解锁技能；常态 jump + 切色释放四马技能；10s 共享 CD、从已解锁池中随机抽技能 | 碰撞体、动画状态机、技能调度中心 |
| 2 | 驷 | 入场与主马同框；播放入场动画后**变形为四马表现**并驱动离场逻辑 | 可与「四马合体对象」为同一 PackedScene 的两阶段，或独立 Timeline 控制 |
| 3 | 灰马（单马） | 首只进场单马；退场后由白马接替 | 与白马/黑马/红马可同一基类，不同 `HorseId` |
| 4 | 白马（单马） | 第二阶段单马；召唤「剑」远程物 | |
| 5 | 黑马（单马） | 第三阶段单马；分裂分身 | |
| 6 | 红马（单马） | 第四阶段单马；召唤炸弹 | |

**四马「同一对象」实现建议**：一个 `CharacterBody2D`（或 `Node2D` + 子动画体）挂载 `HorseVisual`：根据 `HorseId` 切换 `Sprite2D` 图集 / `AnimationPlayer` 库，逻辑层只认 `HorseId`，避免复制四份 AI 脚本。

## 3. 血量阶段与流程（与主马 HP 绑定）

以下以**主 Boss 血量百分比**为触发条件（若实际用统一血条，需明确是否五马共享一条血；推荐：**仅主马可受伤害**，阶段只读主马 HP，单马阶段可无敌或独立演出血条不显示）。

| 血量阈值 | 流程要点 | 主马技能状态 |
|----------|----------|----------------|
| 入场 ~ 100% | 主马 + 驷入场 → 播动画 → 驷变为四马 → **四马离场**（移出屏幕或切场景层隐藏）→ **灰马单独进场** | 主马**仅灰马技能**（与灰马同步） |
| ≤ 80% | **灰马退场**（动画 + 离场）→ **白马进场** | 主马可用 **灰 + 白** 技能 |
| ≤ 60% | 白马退场 → **黑马进场** | 主马可用 **灰 + 白 + 黑** |
| ≤ 40% | 黑马退场 → **红马进场** | 主马可用 **四马全部** 技能 |
| ≤ 20% | **提示**：即将有强力攻击；分支见第 4 节 | 技能集已满；进入特殊演出判定 |
| 过场后 | 五马**同时回到场地**围攻主角 | 主马继续作为技能中枢或转为多目标（见实现建议） |

**退场 / 进场**：统一用 `Tween` 位移 + `AnimationPlayer`「离场」「入场」；用 `Area2D` 或屏幕边界检测判定「已离场」再刷下一只。

**驷（`boss_si.tscn`）当前动画命名**：`divide`（变四马）、`horses run`（四马离场）、`jump`（常态）。

## 4. 20% 血：商鞅防御分支与即死

### 4.1 触发条件

- 主马 HP ≤ 20%（且本段演出未触发过）。
- UI 提示玩家：**即将有强力攻击**，引导使用**放置商鞅**进行防御。

### 4.2 分支 A：已放置商鞅

1. 五匹马（或主马 + 四马实体）生成**伸向商鞅的绳子**（道具 / 场景实例）：锁链/绳视觉上连向商鞅**四肢 + 头**（5 个锚点或 5 条 Line2D / 骨骼）。
2. 商鞅播放**被束缚 / 失肢**相关动画；与现有「肢体收集 / 失去肢体」存档或剧情状态对接（需与 `商鞅` 脚本、存档键对齐）。
3. 演出：五马将肢体**拉离屏幕**（拖动物体 + 淡出或移出摄像机）。
4. 演出结束后进入第 5 节「五马同场」阶段。

### 4.3 分支 B：未放置商鞅

- 对玩家施加**即死**（可直接 `stats.health = 0`、或专用 `instant_kill` 信号，与项目统一死亡流程一致）。

### 4.4 实现要点

- 用 `enum BossPhase { ..., FINAL_WARNING, CHAIN_CINEMATIC, ALL_HORSES }` 防止重复触发。
- 放置商鞅的判定：监听「召唤物落地 / 进入防御组」或现有 `Player` 召唤 API；给窗口期（例如 N 秒内有效），避免误杀。
- 过场期间：`set_process_input(false)` 或锁定玩家，仅播动画与 QTE/无操作演出（按你期望）。

---

## 5. 过场后：五马同场围攻

- 四马 + 主马（或「驷」已拆为四实体 + 主马共 5 个可攻击单位）**同时进入战斗区域**。
- **每匹马使用第 8 节已定义的技能**；**主马拥有全部四种单马能力**，并通过切色动画调用对应技能槽；主马 **10s 共享 CD**、从当前已解锁技能池中**随机**抽取一个技能释放（见第 8 节末）。
- AI：可为每马挂 `HorseBrain` 组件，状态 `Chase / JumpAttack / UseAbility`；主马额外 `SkillPalette` 根据当前解锁集合与 CD 调度出招。

## 6. 主马：跳跃、体型、切色与技能释放

### 6.1 常态

- **向前 jump**：独立动画轨；跳跃高度 `H_main`（导出变量，大于四马 `H_minor`）。
- **常态颜色**：一种默认色（与「未切到其他马技能」一致）。

### 6.2 释放「某马技能」时

1. 播放**切色动画** → 颜色与对应马一致。
2. 调用该马对应技能逻辑（可委托给子节点 `Ability_XXX` 或静态 `HorseAbilities.use(id)`）。
3. 技能结束（动画 finished 或技能状态机 `ENDED`）：
4. 再播**切回常态色**动画；
5. 恢复**常态 jump** 动画与位移逻辑。

### 6.3 实现建议（Godot）

- `AnimationTree` + `StateMachine`：状态 `Idle / Jump / CastIntro / CastLoop / CastOutro / ColorSwitch`。
- 或用 `AnimationPlayer` + 代码切 `current_animation`，用 `animation_finished` 串阶段。
- 技能与颜色解耦：`enum HorseColor { Grey, White, Black, Red }`，`request_skill(color)` 内部先 `play_switch_to(color)`。

## 7. 道具与召唤物（动画与判定）

### 7.1 伸向商鞅的绳子

| 项目 | 说明 |
|------|------|
| 用途 | 20% 过场，视觉连接五马与商鞅五肢 |
| 实现要点 | `Line2D` 每帧 `set_point_position` 跟随锚点；或 `Bone2D`；结束时 `queue_free` |

### 7.2 白马「剑」远程攻击物

| 项目 | 说明 |
|------|------|
| 生成位置 | 在**白马位置**被召唤 |
| 动画（实际命名） | `ready`（被召唤）→ 飞行阶段（保持碰撞）→ `over`（消失）后销毁 |
| 运动 | 面向**正面方向**横向直线飞行 |
| 碰撞销毁 | 碰到**障碍物**、**玩家**或**商鞅**后播放**消失动画**，再销毁 |
| 碰撞与分组 | 与 `player_bullet` / `机关` 层区分，避免误伤 |

### 7.3 红马炸弹

| 项目 | 说明 |
|------|------|
| 生成逻辑 | **主角当前位置**生成；生成后**静止**，不跟随玩家移动 |
| 动画（实际命名） | `ready`（被召唤）→ `boom`（爆炸） |
| 伤害判定 | **仅在爆炸动画播放帧**内对玩家造成伤害（与预警/待机区分） |
| 生命周期 | 爆炸动画播放完毕后销毁 |
| 可选 | 预警圈 `Sprite2D` alpha 脉动（若与「预警动画」分离） |

## 8. 四马技能与主马规则（已定稿）

### 8.1 四马技能一览

| 马 | 技能名（工作名） | 效果简述 | 动画与流程 | 冷却 / 持续 | 主马共用时的差异 |
|----|------------------|----------|------------|---------------|------------------|
| 灰马 | 奔跑 | 平平无奇的奔跑，**持续 5s** | `grey_ready`（进入奔跑）→ `grey_run`（循环）→ `grey_over`（退出）→ `grey_jump`（回到常态移动） | **CD 10s**（与持续 5s 错开由实现保证） | 与单马一致 |
| 白马 | 召剑 | 召唤「剑」远程攻击物攻击 | `white_ready`（预警）→ `white_call`（召唤）并生成剑实例（见第 7.2 节）→ `white_jump` | 由白马 AI / 资源配置 | 主马可**一次性召唤两把剑**（两次生成或一次生成双实例，实现时二选一并写清） |
| 黑马 | 分裂 | 分裂出**第二个黑马**；本体与分身**同时进入 jump**；分裂后**不可再次分裂**直至本轮结束 | `black_ready`（预警）→ `black_create`（召唤分身）→ 本体/分身 `black_jump`；**持续 5s** 后分身消失（补 `disappear` 动画） | 分身有**独立血量**；**10s** 后可再次使用分裂技能 | 与单马一致 |
| 红马 | 召爆 | 在**主角当前位置**召唤炸弹，炸弹**不跟随**玩家 | `red_ready`（预警）→ `red_call`（召唤）并生成炸弹（见第 7.3 节）→ `red_jump` | 由红马 AI / 资源配置 | 主马可**连续两次**「预警 + 召唤」流程，从而**召唤两次爆炸**（两次完整序列） |

### 8.2 主马技能规则（阶段 + CD + 随机）

- **随阶段解锁**：与第 3 节血量阶段一致，主马技能池逐步加入灰 → 白 → 黑 → 红对应技能。
- **共享 CD**：使用任一已解锁技能后进入 **10s 全局冷却**，期间不可再放任何马技能。
- **随机抽取**：CD 结束后，从**当前已解锁技能池**中**随机**选一个技能释放；释放前仍走对应马的**切色动画**，结束后切回常态 jump（见第 6 节）。

### 8.3 主马动画名与技能对应（来自 `boss_horse_main.tscn`）

- 常态移动：`jump`。
- 切色动画：`to grey`、`to white`、`to_black`、`to red`（注意只有黑色是下划线命名）。
- 灰马技能链：`grey_ready` → `grey_running` → `grey_over`。
- 白马技能链：`white_call`（召唤段）。
- 黑马技能链：`black_ready` → `black_call`。
- 红马技能链：`red_ready` → `red_call`。

### 8.4 单马动画名与技能对应（来自 `boss_horse_minor.tscn`）

- 灰马：`grey_ready` → `grey_run` → `grey_over`，常态为 `grey_jump`。
- 白马：`white_ready` → `white_call`，常态为 `white_jump`。
- 黑马：`black_ready` → `black_create`（分裂）→ `black_jump`。
- 红马：`red_ready` → `red_call`，常态为 `red_jump`。
- 说明：分身“消失”动画当前未在单马场景中命名为独立轨道，若仍需要演出，建议补充 `black_disappear` 并在代码里串接。

### 8.5 实现映射建议（便于程序对照）

- 灰马：`grey_ready` 进入奔跑，`grey_run` 循环，定时 `5s` 后 `grey_over` 收招并回 `grey_jump`；技能 CD `10s`。
- 白马：`white_ready` → `white_call` 同步实例化 `ProjectileWhiteHorse`；主马分支保留双剑逻辑（两次生成或单次双发）。
- 黑马：`black_ready` → `black_create` 复制分身并让本体/分身进入 `black_jump`；`5s` 后分身消失并 `queue_free`；技能 CD `10s`。
- 红马：`red_ready` → `red_call` 中途实例化 `BombRedHorse`；主马分支执行两套连续召爆。

## 11. 开发顺序建议（实现里程碑）

1. 场景占位 + 主马受击 + 血条 + 阶段枚举与日志。
2. 入场 Timeline：主马 + 驷动画链；驷切四马视觉并离场。
3. 灰马进场 + 主马仅灰技能 + 80% 切换白马。
4. 依次 60% / 40% 黑马、红马。
5. 20% UI 提示 + 商鞅检测 + 绳子过场 / 即死分支。
6. 五马同场 AI + 主马四技能 + 10s 共享 CD + 随机池 + 切色与 jump 恢复。
7. 按第 7～8 节对接「剑」「炸弹」与四马动画资源并联调。
