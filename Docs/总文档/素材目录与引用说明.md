# 素材目录与引用说明

本文档是工程内 **自有素材** 的查阅入口：说明 `assets/资源总库/` 的分类规则、各子目录用途，以及 **仍留在原路径** 的内容（脚本、场景、插件等）。

**资源总库根路径**：`res://assets/资源总库/`

## 2. 按场景查找（快速索引）

### World1 / 通用关卡

- **背景 / 远景**：`01_图像_背景/`（如 `背景.png`、`高楼 学校背景.png`、`school.png`）
- **地形图块**：`02_图像_地图/`（`地.png`、`墙.png`）
- **机关贴图**：`08_图像_机关/`
- **通用音效**：`10_音频/`（机关脚本里常用 `jump.mp3` 作占位触发音等）

### World2

- **存档点等**：`07_图像_World2/`
- **仍引用 World3 预制体**（如存档点场景）：逻辑在 `system/levels/world3/props/`，贴图在 `06_图像_World3/props/`

### World3 Boss 战

- **马与驷马图集**：`06_图像_World3/bosses/`（灰/白/黑/红/头马/驷马等 PNG）
- **投射物 / 心剑 / 存档点图**：`06_图像_World3/props/`
- **随机块 UI 图**：`06_图像_World3/random_pieces/`
- **场景气层用图**：`06_图像_World3/` 根下 `马场中.png`、`马场后.png`（若场景引用已指向此路径）

### Dialogic / 剧情

- **角色与时间线**：`12_Dialogic工程/Dialogic/` 与根级 `*.dtl`
- **工程配置**：`project.godot` 的 `[dialogic]` 下路径已全部指向 `12_Dialogic工程/...`
- **气泡层**：`addons/dialogic/.../text_bubble.tscn` 中气泡图、水滴音效路径指向资源总库（插件内场景需随项目路径维护）

### 玩家 / 敌人

- **主角**：贴图在 `04_图像_玩家/real player/`；逻辑在 `entities/player/real player/`
- **墨弹**：`04_图像_玩家/bullet/墨.png`
- **教师 / 蚊子**：`06_图像_敌人/teacher/`、`bullet/`

## 3. 未迁入「资源总库」的素材相关路径

以下内容 **故意保留**在原目录，便于与脚本、场景同目录维护：

| 类型 | 路径示例 | 说明 |
|------|-----------|------|
| 场景与脚本 | `entities/**.tscn`、`entities/**.gd`、`system/**.tscn`、`system/**.gd` | 非二进制素材 |
| 项目图标 | `res://icon.svg` | 根目录 |
| 第三方插件 | `addons/dialogic/**`（除已改路径的引用） | 插件自带示例资源体积大，一般不迁入总库 |
| 音频总线等 | `default_bus_layout.tres` | 根目录配置 |

## 4. 新增素材时的建议流程

1. 按 **类型** 放入上表对应子目录（音频一律进 `10_音频/`，除非明确是某关卡独占可放 `06_图像_World3/` 旁单独子目录）。
2. 在 Godot 编辑器中 **拖入场景** 或写 `preload("res://assets/资源总库/...")`，避免硬编码旧路径 `res://assets/xxx`（已废弃根目录散装规则）。
3. 若批量改名 / 挪目录，可复用 `tools/move_media_to_ziyuanku.py` 的思路：先搬文件，再全工程替换 `res://` 字符串，并检查 `.import` 内 `source_file=`。
