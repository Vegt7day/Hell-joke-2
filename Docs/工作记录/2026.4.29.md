## 一、贴图污染修复（boss_horse_minor.gd）

### 问题
小黑马分身播放 `black_jump` 动画时，会将小灰马的 `AtlasTexture_7yfle.atlas` 覆盖为黑马贴图，导致灰马变黑且使用黑马动画。

### 根因
`boss_horse_minor.tscn` 中的 `AtlasTexture_7yfle` 是共享的 `sub_resource`。Godot 实例化场景时所有实例共享同一个对象。任一实例修改其 `atlas` 属性即污染所有实例。

### 验证
创建测试场景 `system/levels/world3/tests/test_horse_texture_pollution.tscn` 和对应脚本 `.gd`，完整复制了 world3 的 `_get_or_spawn_minor` / `_play_minor_jump` / `_set_horse_movement` 逻辑。运行结果：
```
[TEST] Grey AtlasTexture.atlas init: res://assets/.../黑马.png
[POLLUTION] Frame 174: Grey AtlasTexture.atlas changed!
[RESULT] 灰马贴图 被 黑马分身动画 污染! — 1122 polluted frames
```

### 修复
在 `_ready()` 函数最顶部添加独立复制：

```gdscript
if sprite_2d and sprite_2d.texture and sprite_2d.texture is AtlasTexture:
    sprite_2d.texture = sprite_2d.texture.duplicate()
```

**文件变更：** `system/levels/world3/bosses/boss_horse_minor.gd` (+4 lines)

## 二、弹幕滚动坐标系修复（boss_horse_main.gd）

### 问题
直播间滚动语句的移动会跟随角色/Camera 偏移，而非固定在 UI 层。

### 根因
1. `create_tween()` 调在 `self`（CharacterBody2D，世界空间节点）上，tween 生命周期绑定在游戏世界节点
2. `spawn_x` 计算使用 `feed_root.size.x`，未做 viewport 绝对坐标转换

### 修复

**a) tween 归属修复：**
```gdscript
# 旧: var tw := create_tween()
# 新: var tw := feed_root.create_tween()
```

**b) 坐标改用 viewport 绝对坐标：**
```gdscript
# 旧: var spawn_x := feed_root.size.x + skill_feed_spawn_offset_x
# 新:
var vp_width := feed_root.get_viewport_rect().size.x
var feed_screen_left := feed_root.global_position.x
var spawn_x := vp_width + skill_feed_spawn_offset_x - feed_screen_left
var end_x := -label_w - 24.0 - feed_screen_left
```

## 三、弹幕白色半透明圆角底子（boss_horse_main.gd）

### 需求
为弹幕文字添加白色半透明圆角矩形背景；"进入了直播间"消息的底子比技能打赏消息更大。

### 实现
改造 `_create_skill_feed_row`：
- 返回值从 `RichTextLabel` 改为 `Control` 容器
- 容器内含 `Panel` 节点，使用 `StyleBoxFlat` 实现白色半透明圆角背景
- 新增 `is_entry` 参数控制底子大小：

| 类型 | 透明度 | 圆角 | margin |
|------|--------|------|--------|
| 技能打赏 | 45% 白 | 8px | 10/4 |
| 进场消息 | 60% 白 | 10px | 16/8 |

- Panel 大小通过 `row.resized` 信号自适应文本内容

### 连带变更
- `_skill_feed_lane_active` 类型：`Array[RichTextLabel]` → `Array[Control]`
- `_push_skill_feed_message` 新增 `is_entry: bool = false` 参数
- `post_minor_entry_broadcast` 调用处传入 `is_entry=true`
- `_pick_danmaku_lane` / `_is_danmaku_fully_inside_right_boundary` 适配 Control 容器类型
- Lint 检查：零错误

**文件变更：** `system/levels/world3/bosses/boss_horse_main.gd` (约 40 行改动)
