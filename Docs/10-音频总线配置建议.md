# 音频总线配置建议（文字地狱重制版）

本文档给出当前项目可用的音频总线规划、数量建议、典型路由方式与扩展需求清单。

---

## 1. 结论：建议至少 8 条总线（基础稳定版）

按你当前需求，推荐先落地这 8 条：

1. `Master`（总输出）
2. `BGM`（场景/流程音乐）
3. `BGM_Boss`（Boss 战音乐，便于独立压限与切换）
4. `SFX_Player`（主角动作、攻击、受击、能力）
5. `SFX_Mechanism`（机关：开关、门、窗、桶、水、陷阱）
6. `SFX_Enemy`（敌人本体行为音）
7. `SFX_EnemyBullet`（敌方子弹）
8. `UI`（按钮、确认、取消、悬停）

> 如果你想先简化，也可把 `BGM_Boss` 并入 `BGM`，把 `SFX_EnemyBullet` 并入 `SFX_Enemy`，先用 6 条总线启动，后续再拆。

---

## 2. 为什么建议这样拆

- **BGM 与 BossBGM 分离**：便于做平滑切歌、Boss 时整体压低 SFX 或相反。
- **玩家/机关/敌人分离**：调混音时可以快速定位问题（比如“机关太吵盖住角色动作”）。
- **敌人与敌方子弹分离**：弹幕场景可单独限幅，防止密集射击刺耳。
- **UI 独立**：暂停菜单、设置界面、对话系统都能单独调音。

---

## 3. 你已提出需求对应到总线

- 场景音乐（含 Boss 切换） -> `BGM` / `BGM_Boss`
- 主角音效 -> `SFX_Player`
- 机关音效 -> `SFX_Mechanism`
- 敌人和敌人子弹 -> `SFX_Enemy` / `SFX_EnemyBullet`
- UI 按键 -> `UI`

---

## 4. 可能还会用到的需求（建议预留）

以下是项目后续常见扩展，可按阶段新增总线：

1. `Ambience`（环境循环音）
   - 风声、雨声、地下室嗡鸣、电流噪声、机关底噪

2. `Voice`（语音/对白）
   - 角色语音、NPC 语气词、剧情播报

3. `Cinematic`（过场特效音）
   - 演出关键音、镜头切换音、过场冲击音

4. `Narration`（旁白）
   - 与 `Voice` 分离，方便字幕旁白独立控制

5. `Debug`（调试音）
   - 临时测试音效，不污染正式混音

6. `Accessibility`（辅助提示音）
   - 无障碍提示、交互提示、导航提示

7. `DialogUI`（对话系统 UI）
   - 如果你后续 Dialogic 文本打字音、选项音需要独立于普通 UI

---

## 5. 推荐的总线树（第一版）

建议结构：

- `Master`
  - `BGM`
  - `BGM_Boss`
  - `SFX`
    - `SFX_Player`
    - `SFX_Mechanism`
    - `SFX_Enemy`
    - `SFX_EnemyBullet`
  - `UI`

这样做的好处是：你可以一键调 `SFX` 总体，再细调子类。

---

## 6. 关键混音策略建议

1. **Boss 战切歌**
   - 保留 `BGM` 与 `BGM_Boss` 两个播放器，交叉淡入淡出（0.5~1.5s）

2. **SFX 峰值控制**
   - 在 `SFX` 或 `Master` 上挂轻量 Limiter，防密集触发爆音

3. **机关去重**
   - 你现在已有 `MechanismSfxBus`，建议总线指定到 `SFX_Mechanism`

4. **UI 保持清晰**
   - `UI` 总线压限少一点，瞬态保留，避免“糊”

5. **统一响度基线**
   - BGM、SFX、UI 各自目标响度先定一个基线，再微调（例如相对平衡）

1. [x] 在 Godot Audio Bus 面板建立上述总线树（已用 `MechanismSfxBus` 在运行时自动确保总线存在与路由）

4. 实机跑一遍 3 类场景：
   - 探索（常态）
   - 机关密集场景
   - Boss 战切歌场景
5. 根据体感调每条 bus 的增益与压限

- `Master`
