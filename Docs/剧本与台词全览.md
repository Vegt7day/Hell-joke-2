中学生穿越到地狱世界，遇见被五马分尸的商鞅遗骸。

触发：进入 World 2 自动播放（首次）
角色：商鞅、中学生

> **商鞅**：小友……小友……
>
> **中学生**：！？
>
> **中学生**：你是谁，这是哪儿
>
> **商鞅**：我的真名已经消散在历史中了，这里是地狱笑话的世界

> **中学生**：⊙o⊙）？我知道了，你是刑天！

**商鞅肢体的分布：**

- 右：ShangYangLimb2 (96, -160)
- 左中：ShangYangLimb3 (-704, -192)

#### 8. 入场引导（商鞅教导交互心与剑.dtl）

#### 10. Boss 战阶段与直播间弹幕

Boss 血量分 5 个阶段，阶段切换时弹幕滚动播报进场消息。

| 血量阶段 | 播报内容 |
|----------|----------|
| 100% ~ 80%（灰马 Solo） | **灰马** 进入了直播间 |
| 80% ~ 60%（白马 Solo） | **白马** 进入了直播间 |
| 60% ~ 40%（黑马 Solo） | **黑马** 进入了直播间 |
| 40% ~ 20%（红马 Solo） | **红马** 进入了直播间 |

**技能释放弹幕：**

每匹马释放技能时，屏幕滚动播放打赏消息：

| 马 | 技能名 | 弹幕格式 |
|----|--------|----------|
| 灰马 | 爱的冲撞 | 灰马 打赏了 爱的冲撞 |
| 白马 | 认真一剑 | 白马 打赏了 认真一剑 |
| 黑马 | 诡影兵团 | 黑马 打赏了 诡影兵团 |
| 红马 | 猩红风暴 | 红马 打赏了 猩红风暴 |
| 皇马 | 白马技能 *2 | 皇马 打赏了 认真一剑\*2 |
| 皇马 | 红马技能 *2 | 皇马 打赏了 猩红风暴\*2 |

**颜色体系：** 灰马 #B8BBC7 / 白马 #F4F7FF / 黑马 #8B90A8 / 红马 #FF6B6B / 皇马 #FFD34D

---

#### 11. 致命预警（商鞅提醒按f.dtl）

触发：Boss 血量降至 20% 以下，全屏预警面板弹出
角色：商鞅

> **商鞅**：小友！快按"f"，我上次就是栽到这招上了

同步显示商鞅召唤提示，玩家可以在战斗中召唤商鞅协助。

---

#### 12. 商鞅五马分尸 —— 含商鞅在身边时

触发：Boss 血量 ≤ 20%，商鞅存在于场，五马拉扯绳索演出完成后

演出流程：
1. 五匹马从各自出生点外被 tween 拉入场
2. 绳索从 0 延伸到商鞅四肢（2 秒）
3. 马匹开始向外走，商鞅肢体跟随拖动（4.2 秒）
4. 绳子锁住后弹出提示：「绳索已锁住商鞅的四肢。接下来将进入剧情对话。」
5. 进入对话

> **商鞅**：小友，别看……
>
> **商鞅**：别管我，接下来的路你要自己走了

商鞅变为"幽灵"布景状态（无碰撞，仅场景）。

---

#### 12b. 商鞅不在身边 —— 玩家即死分支

触发：Boss 血量 ≤ 20%，商鞅不在场

> 提示：「绳索已缚紧……」

五匹马合围，直接拉玩家出屏幕，即死。

---

#### 13. Boss 死亡（重拾五肢.dtl）

触发：共享血量归零，五马四散逃离
角色：商鞅

> **商鞅**：诶！我没死
>
> **商鞅**：（动不了）
>
> **商鞅**：额，好像又得麻烦你帮我收集肢体了

## 角色弧线总览

### 中学生

| 阶段 | 状态 |
|------|------|
| World 1 开场 | 上课睡觉被老师抓住 |
| World 1 转场 | 借口上厕所逃跑 |
| World 2 开场 | 不想回去，想留在地狱 |
| World 2 收集 | 帮商鞅收集四肢 |
| World 3 开场 | 被推上战场打 Boss |
| World 3 结局 | 目睹商鞅再次被五马分尸 |

**人物性格：** 慵懒、吐槽担当，被迫成为英雄的普通中学生。

### 老教师

| 阶段 | 状态 |
|------|------|
| 开场 | 发脾气教训学生 |
| 攻击阶段 | 释放蚊子弹幕 |
| 放行 | 明知是尿遁但同意 |

**人物性格：** 暴躁但讲道理的教育者，技能名"文字的力量"（其实是蚊子）。

### 商鞅

| 阶段 | 状态 |
|------|------|
| World 2 初见 | 只剩头颅，请求收集四肢 |
| World 2 集齐 | 第一次用手擦屁股（幽默） |
| World 3 引导 | 教学使用"心/剑" |
| World 3 预警 | 提醒按 F，承认自己上次栽了 |
| World 3 分尸 | 被五马再次拉散，告别主角 |
| World 3 结局 | 没死！又要重新收集肢体 |

**人物性格：** 表面严肃但自带幽默光环的引路人 NPC，历史梗（商鞅是被车裂/五马分尸而死）贯穿始终。

## 关卡流程总结

```
World 1 (教室)
  │
  ├─ 课堂开场：教师怒吼 → 蚊子攻击 → 学生吐槽
  ├─ 生存阶段：躲避蚊子 5 秒
  ├─ 尿遁逃脱：借口上厕所 → 教师放行
  ├─ 探索解谜：开关开门、洞、地下
  └─ 出口：学生逃出生天
      │
      ▼
World 2 (商鞅遗迹)
  │
  ├─ 遇见商鞅：刑天？商鞅！搜集四肢
  ├─ 收集肢体：3 个子房间的机关解谜
  ├─ 5 肢集齐：回去看商鞅
  └─ 能力解锁：商鞅感谢 → F 键召唤
      │
      ▼
World 3 (Boss 竞技场)
  │
  ├─ 入场：商鞅引导触碰"心/剑"
  ├─ 灰马阶段 (100~80%)：爱的冲撞
  ├─ 白马阶段 (80~60%)：认真一剑
  ├─ 黑马阶段 (60~40%)：诡影兵团
  ├─ 红马阶段 (40~20%)：猩红风暴
  ├─ 20%预警：商鞅提醒按 F
  ├─ 五马分尸/玩家即死
  ├─ 全马合围最终阶段
  └─ Boss 死亡：商鞅没死，再次收集肢体
```
