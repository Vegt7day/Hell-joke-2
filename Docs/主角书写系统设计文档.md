# 主角「书写」系统设计文档

> 项目：文字地狱重制版 | 引擎：Godot 4.6 | 最后更新：2026-05-04

---

## 一、核心概念

### 1.1 设计哲学

主角的核心能力是「书写」——通过消耗墨水（ink），在世界中生成文字实体。这个能力体现了游戏的"文字地狱"主题：**文字即力量**。

**关键设计理念**：
- **即时性**：所有书写动作在 0.3-0.5 秒内完成（播放 draw 动画）
- **代价感**：墨水消耗让每次书写都有战略意义
- **组合性**：四个子系统可以互相配合，创造复杂策略
- **视觉化**：所有实体都以文字形式呈现，保持游戏的美学统一

### 1.2 四个子系统

| 子系统 | 代号 | 核心作用 | 交互方式 | 墨水成本 |
|--------|------|----------|----------|----------|
| 召唤 | SUMMON | 生成文字生物（盟友） | 选中道具 → 点击确认 | 1-3 格 |
| 强化 | ENHANCE | 添加/移除状态效果 | 选中道具 → 点击目标 | 1-3 格 |
| 建造 | BUILD | 生成障碍物/机关 | 选中道具 → 网格瞄准 → 确认 | 1-3 格 |
| 反应 | REACT | 触发环境元素交互 | 选中道具 → 网格瞄准 + 方向 → 确认 | 1-3 格 |

### 1.3 书写动画

所有子系统激活时都会播放 draw 动画（复用已有资源），消耗墨水格。动画流程：

```
选中道具 → 按下使用键 → 播放 draw 动画（0.3s） → 消耗墨水 → 执行效果
```

**动画阶段**：
1. **准备阶段**（0-0.1s）：主角举起笔，墨水开始消耗
2. **书写阶段**（0.1-0.25s）：文字在空中成形
3. **完成阶段**（0.25-0.3s）：文字实体固定到世界中

## 二、墨水系统

### 2.1 墨水资源

- **当前墨水**：通过墨水格显示（已有）
- **最大墨水**：初始 4 格，可通过升级/道具增加
- **墨水恢复**：每 5 秒恢复 1 格（脱战时加速恢复）

### 2.2 墨水消耗规则

每种道具使用时消耗固定墨水量，与道具等级/稀有度相关：

| 墨水消耗 | 道具类型示例 | 战略定位 |
|----------|-------------|----------|
| 1 格 | 基础召唤（小兵）、单体强化、单格建造、点状反应 | 高频使用，基础操作 |
| 2 格 | 进阶召唤（精英）、范围强化、多格建造、线状反应 | 中频使用，进阶操作 |
| 3 格 | 高级召唤（Boss级）、全体强化、复杂建造、面状反应 | 低频使用，关键操作 |

**设计原则**：
- 1 格道具可以连续使用 4 次（初始墨水）
- 2 格道具可以连续使用 2 次
- 3 格道具只能使用 1 次，需要等待恢复

### 2.3 墨水恢复机制

| 状态 | 恢复速度 | 说明 |
|------|----------|------|
| 脱战 | 1 格/5 秒 | 无敌人接触 |
| 战斗中 | 1 格/10 秒 | 有敌人在屏幕内 |
| 受伤后 | 1 格/15 秒 | 受伤后 3 秒内 |
| 满墨水 | 不恢复 | 已达上限 |

**脱战判定**：
- 屏幕内无敌人（包括子弹）
- 无敌人攻击主角
- 无敌人攻击召唤物

### 2.4 墨水管理策略

玩家需要在以下选择中权衡：
- **连续使用**：快速消耗墨水，获得短期优势
- **蓄力等待**：保留墨水，应对突发情况
- **墨水管理道具**：某些道具可以加速墨水恢复

## 三、召唤系统（SUMMON）

### 3.1 召唤物分类

| 类型 | 代号 | 核心特点 | 战斗风格 | 示例 |
|------|------|----------|----------|------|
| 进攻型 | ATTACK | 自动攻击敌人，高伤害 | 积极进攻 | 商鞅（已有） |
| 防御型 | DEFEND | 吸引仇恨，高血量，低攻击 | 保护主角 | 重 |
| 辅助型 | SUPPORT | 给主角增益（回血/加攻/加速） | 辅助支援 | 恢 |
| 双刃剑型 | DOUBLE | 攻击敌人，但可能碰撞主角造成伤害 | 高风险高回报 | 狂 |

### 3.3 召唤物行为详解

#### 进攻型（ATTACK）

**AI 状态机**：
```
IDLE → DETECT → CHASE → ATTACK → COOLDOWN → (返回 CHASE 或 IDLE)
```

**行为规则**：
1. 检测范围内最近敌人 → 选择目标
2. 向目标移动，保持攻击距离
3. 到达攻击距离后，开始攻击
4. 攻击间隔可配置
5. 目标死亡或超出检测范围 → 返回 IDLE
6. 死亡或超时后消失

**攻击模式**：
- 近战型：冲到敌人身边攻击
- 远程型：在远处发射文字弹幕
- 突进型：快速冲向敌人造成伤害

#### 防御型（DEFEND）

**AI 状态机**：
```
FOLLOW → TAUNT → TAKE_DAMAGE → (返回 FOLLOW)
```

**行为规则**：
1. 跟随主角，保持一定距离
2. 主动吸引敌人仇恨（嘲讽）
3. 被攻击时减少受到的伤害（减伤 50%）
4. 死亡后消失

**特殊能力**：
- **嘲讽**：强制敌人攻击自己，持续 3 秒
- **护盾**：为主角吸收 50% 伤害
- **反击**：被攻击时反弹 10% 伤害

#### 辅助型（SUPPORT）

**AI 状态机**：
```
FOLLOW → BUFF → (返回 FOLLOW)
```

**行为规则**：
1. 跟随主角，保持一定距离
2. 定期给主角添加增益状态
3. 不参与战斗，不吸引仇恨
4. 死亡后消失

**增益类型**：
- **治疗**：每秒恢复 1 HP，持续 5 秒
- **强化**：伤害 +20%，持续 8 秒
- **加速**：移速 +30%，持续 6 秒

#### 双刃剑型（DOUBLE）

**AI 状态机**：
```
IDLE → DETECT → CHASE → ATTACK → COLLISION_CHECK → (返回 CHASE 或 IDLE)
```

**行为规则**：
1. 像进攻型一样移动攻击
2. 但移动路径上碰到主角也会造成伤害
3. 碰撞后双方都被击退
4. 死亡后消失

**平衡机制**：
- 友伤伤害为正常伤害的 50%
- 碰撞后有 1 秒冷却，不会连续友伤
- 主角受伤时，召唤物会被短暂眩晕（0.5 秒）

### 3.4 召唤物上限管理

- 同时存在最多 **3** 个召唤物
- 超出上限时，最早的召唤物自动消失
- 部分道具可临时提升上限（最多 5 个）
- 召唤物数量显示在屏幕左上角

**上限管理逻辑**：
```gdscript
func try_summon(data: SummonData) -> bool:
    if current_summons.size() >= max_summons:
        # 移除最早的召唤物
        var oldest = current_summons[0]
        oldest.despawn()
    # 生成新召唤物
    var summon = create_summon(data)
    current_summons.append(summon)
    return true
```

### 3.5 召唤物与现有系统交互

**与商鞅（已有）的兼容**：
- 商鞅视为进攻型召唤物
- 受上限管理（最多 3 个）
- 保持现有行为不变

**与玩家状态的交互**：
- 玩家死亡 → 所有召唤物消失
- 玩家传送 → 召唤物跟随传送
- 玩家隐身 → 召唤物也隐身

**与敌人的交互**：
- 召唤物可以被敌人攻击
- 召唤物可以吸引敌人仇恨
- 召唤物死亡不影响玩家

## 四、强化系统（ENHANCE）

### 4.1 状态分类

| 类型 | 目标 | 效果示例 | 持续时间 |
|------|------|----------|----------|
| 增益（正面） | 自己/召唤物 | 加攻、加速、回血、护盾 | 3-15 秒 |
| 减益（负面） | 敌人 | 减速、中毒、眩晕、脆弱 | 2-10 秒 |
| 双向 | 任意 | 某些状态对不同目标效果不同 | 可变 |

### 4.2 状态数据结构

### 4.4 状态效果管理器

```gdscript
## 状态管理器
class_name StatusManager extends Node

signal status_added(effect: StatusEffect)
signal status_removed(effect: StatusEffect)
signal status_expired(effect: StatusEffect)

var _active_statuses: Dictionary = {}  # {id: StatusInstance}

func add_status(effect: StatusEffect, source: Node = null) -> bool:
    # 检查是否可叠加
    if _active_statuses.has(effect.id):
        if effect.stackable and _active_statuses[effect.id].stacks < effect.max_stacks:
            _active_statuses[effect.id].stacks += 1
            return true
        else:
            # 刷新持续时间
            _active_statuses[effect.id].timer = effect.duration
            return true
    
    # 添加新状态
    var instance = StatusInstance.new(effect, source)
    _active_statuses[effect.id] = instance
    status_added.emit(effect)
    return true

func remove_status(effect_id: StringName) -> void:
    if _active_statuses.has(effect_id):
        var instance = _active_statuses[effect_id]
        _active_statuses.erase(effect_id)
        status_removed.emit(instance.effect)

func has_status(effect_id: StringName) -> bool:
    return _active_statuses.has(effect_id)

func get_status_value(modifier_type: ModifierType) -> float:
    var total = 0.0
    for instance in _active_statuses.values():
        for mod in instance.effect.effects:
            if mod.type == modifier_type:
                total += mod.value
    return total

func _process(delta: float) -> void:
    # 更新所有状态计时器
    for effect_id in _active_statuses.keys():
        var instance = _active_statuses[effect_id]
        instance.timer -= delta
        if instance.timer <= 0:
            remove_status(effect_id)
            status_expired.emit(instance.effect)
```

### 4.5 强化目标选择

使用强化道具时，需要选择目标：

**快捷操作**：
- **对自己使用**：双击道具 / 快捷键 + Enter
- **对召唤物使用**：选中道具 → 点击召唤物
- **对敌人使用**：选中道具 → 点击敌人（需在范围内）

**范围选择**：
- 部分强化道具支持范围效果
- 使用时显示范围指示器
- 范围内所有合法目标都会受到效果

**选择优先级**：
1. 主角（默认）
2. 距离最近的召唤物
3. 距离最近的敌人

### 4.6 状态效果交互

**状态冲突规则**：
- 「燃」+「水」= 「燃」消失
- 「冰」+「火」= 「冰」融化
- 「力」+「弱」= 抵消（保留较高优先级）

**状态优先级**：
- 高优先级状态可以覆盖低优先级状态
- 同优先级状态按添加时间排序
- 最多同时存在 5 个状态（超过时移除最早的状态）

### 5.3 信号系统详解

建造物可以形成简单的逻辑电路：

```
[压力板] --脉冲信号--> [石门] (开门 1 秒)
[压力板] --持续信号--> [炮台] (激活炮台)
[压力板] --翻转信号--> [灯] (切换开/关)
[中继器] --转发信号--> [多个接收器] (同时激活)
```

**信号类型**：
- **脉冲信号**：触发后持续 1 秒
- **持续信号**：踩住时持续，松开时停止
- **翻转信号**：触发后切换状态（开/关）

**信号传递规则**：
- 信号在 1 格内传递
- 中继器可以延长信号距离
- 同一信号 ID 的触发器可以同时激活多个接收器

### 5.4 建造规则详解

1. **网格对齐**：所有建造物必须对齐到世界网格（16×16 像素）
2. **建造范围**：以主角为中心，半径 **4 格** 内
3. **重叠限制**：不能在已有建造物/地形上叠加
4. **数量限制**：同时最多 **10** 个建造物
5. **自动拆除**：超出建造范围或主角死亡时，建造物保留 **30 秒** 后消失
6. **破坏规则**：建造物可被敌人攻击/反应物破坏

### 6.4 目标物类型详解

**建筑/地形**：
- **易燃建筑**：可被点燃，持续燃烧一段时间（10 秒），燃烧时有火焰效果
- **易老化建筑**：可被腐蚀，防御降低（50%），持续 15 秒
- **水源**：可被冻结/蒸发，影响周围环境
- **冰面**：可被融化，变为水面

**敌人**：
- **火**：持续伤害（2 点/秒），持续 5 秒
- **水**：减速 40%，持续 6 秒
- **腐**：防御降低 50%，持续 8 秒
- **冰**：冻结 3 秒，无法移动

**召唤物**：
- 可被友方反应物增益（如「力」状态）
- 可被敌方反应物减益（如「缓」状态）
- 友方反应物不会对召唤物造成伤害

### 6.5 方向性操作详解

**非方向性（点状）**：
- 选中道具 → 点击位置 → 在该位置释放
- 作用范围为圆形区域（半径 1 格）

**方向性（线状）**：
- 长按鼠标左键 → 确定起始点
- 拖动鼠标 → 显示方向指示器（虚线箭头）
- 松开左键 → 从起始点向拖动方向释放
- 作用范围为直线（长度 8 格）

**方向性（扇形）**：
- 长按鼠标左键 → 确定起始点
- 拖动鼠标 → 显示扇形指示器
- 松开左键 → 从起始点向拖动方向释放
- 作用范围为扇形（角度 60 度，半径 4 格）

**操作流程**：
```
1. 选中反应道具（快捷栏/背包）
2. 进入瞄准模式（显示网格+光标）
3a. [非方向] 点击位置 → 确认释放
3b. [方向性] 长按左键 → 拖动确定方向 → 松开释放
4. 播放反应动画 → 消耗墨水 → 执行效果
```

### 6.6 反应系统与现有系统交互

**与强化系统的交互**：
- 反应物可以触发强化状态（如「燃」状态）
- 强化状态可以被反应物消除（如「水」消除「燃」）

**与召唤系统的交互**：
- 召唤物可以被反应物增益/减益
- 召唤物可以触发反应（如「狂」被「水」消除）

**与建造系统的交互**：
- 建造物可以被反应物破坏（如「火」点燃木栅栏）
- 建造物可以被反应物增强（如「冰」冻结石墙，增加防御）

### 7.3 瞄准模式详解

**点选模式（POINT）**：
- 鼠标移动 → 网格光标跟随
- 左键点击 → 选中该格
- 右键点击 → 取消选择

**方向模式（DIRECTION）**：
- 鼠标移动 → 网格光标跟随
- 左键按下 → 确定起始点，进入拖动状态
- 鼠标拖动 → 显示方向线（虚线箭头）
- 左键松开 → 确定方向，执行反应
- 右键点击 → 取消选择

**取消操作**：
- 按 ESC → 退出瞄准模式
- 按右键 → 取消当前选择
- 切换道具 → 退出瞄准模式

### 7.4 视觉反馈详解

**正常状态**：
- 网格边框：半透明白色（alpha 0.3）
- 可建造范围：半透明绿色（alpha 0.2）
- 超出范围：半透明红色（alpha 0.2）

**悬停状态**：
- 光标位置：高亮黄色边框（alpha 0.8）
- 建造预览：半透明青色（alpha 0.5）

**方向模式**：
- 起始点：绿色高亮（alpha 0.8）
- 方向线：黄色虚线（宽度 2 像素）
- 终点：红色高亮（alpha 0.8）
- 影响范围：半透明黄色扇形/矩形

**确认状态**：
- 选中格：闪烁白色边框
- 建造物预览：半透明白色（alpha 0.7）
