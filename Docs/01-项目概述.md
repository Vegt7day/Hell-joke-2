# 01 - 项目概述

## 游戏类型与核心玩法

**文字地狱重制版**是一款基于 **Godot 4.x** 的 **2D 横版动作与叙事混合**作品：玩家在关卡内移动、跳跃、用「墨水」发射子弹（`ink` 场景），并与门、开关等可交互物及 **Dialogic** 驱动的对话时间线交互。首关逻辑（`WorldController`）在教师介绍对话后进入限时生存（默认约 5 秒），教师发射「蚊子」类子弹附着扣血；玩家血量归零则失败，坚持到计时结束或教师血量机制触发胜利条件等（详见 `03-核心系统分析.md`）。

**设计要点**：将「文字 / 对话」与平台跳跃、资源（墨水）管理结合；关卡控制器通过 **Dialogic 时间线** 与 **信号桥接**（`DialogicUtil.autoload().signal_event`）控制玩家能否移动。

---

## 技术栈概览

| 类别 | 选型 |
|------|------|
| 引擎 | **Godot 4.6**（`project.godot` 中 `config/features` 含 `"4.6"`） |
| 渲染 | Forward Plus；Windows 默认 D3D12 |
| 叙事插件 | **Dialogic**（`addons/dialogic`，`editor_plugins` 已启用） |
| 物理 | 2D 在独立线程（`2d/run_on_separate_thread=true`）；项目设置中 3D 引擎为 Jolt（与本作 2D 主玩法弱相关） |
| 数据格式 | 运行时存档为 **JSON**（`user://data.sav`）；对话为 Dialogic 的 **`.dtl` / `.dch`** |
| 其他工具 | `assets/audio_changer.py` 等辅助脚本（音频批处理，非运行时依赖） |

## 编译与运行方法

1. **环境**：安装与工程匹配的 **Godot 4.6**（或与 `config/features` 兼容的 4.x 编辑器）。
2. **打开工程**：在 Godot 中导入本目录（包含 `project.godot` 的根路径）。
3. **运行**：主场景由 UID 解析为 `res://system/scene/title_screen.tscn`。

```ini
# project.godot（节选）
[application]
config/name="文字地狱重制版"
run/main_scene="uid://cge0gbh6xo5ib"

[autoload]
Dialogic="*uid://ds2q0uclmolvu"
Game="*uid://cwnvqmdyl2j3i"
DialogicRegistry="*uid://buxvgwfat3tfx"
```

4. **操作**（默认 `project.godot` 中 `[input]`）：`A/D` 左右、`W` 跳跃、`J` 攻击、`E` 交互、`F` 召唤（在 `Player` 脚本中还有键盘到动作的映射）；`Esc` 触发 `Game.save_game()`（见 `game.gd` 的 `_unhandled_input`）。
5. **导出**：仓库内**未**包含 `export_presets.cfg`，若需发布需在编辑器中配置导出模板并生成该文件（勿将敏感密钥写入版本库）。

## 设计决策摘要

- **Game 作为场景型自动加载**：使用 `CanvasLayer` + 全屏 `ColorRect` 做转场淡变，同时持有全局 `PlayerStats`（`Stats` 实例），避免纯脚本单例与编辑器中可视化调试脱节。
- **Dialogic 集中配置**：角色与时间线路径写在 `project.godot` 的 `[dialogic]`，便于编辑器与运行时一致。
- **单一可操作角色**：仅 `Player`（`entities/player/real player/student.gd`）；旧版 `Student` 已移除。

## 代码示例：标题界面进入游戏

标题按钮直接调用自动加载单例 `Game` 的方法（耦合低、适合小型项目）：

```gdscript
# system/scene/title_screen.gd
func _on_new_game_pressed() -> void:
	Game.new_game()

func _on_load_game_pressed() -> void:
	Game.load_game()
```

**说明**：`new_game()` 已在切场景前显式重置会话状态，不再依赖未使用的 `params["init"]`（见 `02-架构设计.md` 历史说明）。
