## 6. 音频总线架构

所有 SFX 通过 `MechanismSfxBus` (Autoload) 路由，关键常量定义在 `mechanism_sfx_bus.gd`：

```
Master
├── BGM
├── BGM_Boss
├── SFX
│   ├── SFX_Player
│   ├── SFX_Mechanism
│   ├── SFX_Enemy
│   └── SFX_EnemyBullet
└── UI
```

`request_once(event_key, stream, cooldown_ms)` 调用方在上方 SFX 表格中逐一标注。
