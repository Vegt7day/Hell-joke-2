## 3. 实现该清单需修改的文件

### 需要添加 AudioStreamPlayer 节点的 .tscn 文件（4 个）

- `system/levels/world3/props/projectile_white_horse.tscn` — 添加命中音效节点
- `system/levels/world3/props/bomb_red_horse.tscn` — 添加爆炸音效节点（可能需要两个：爆炸 + 哑火）
- `system/levels/world3/bosses/boss_horse_main.tscn` — 添加灰马冲刺音效节点
- `system/scene/title_screen.tscn` — 添加 UI hover/click 音效节点

### 需要添加 .play() 调用的 .gd 文件（5 个）

- `system/levels/world3/props/projectile_white_horse.gd` — `_run_hit_and_despawn()` 中加命中音效
- `system/levels/world3/props/bomb_red_horse.gd` — `_run_red_bomb_sequence()` 中加爆炸音效
- `system/levels/world3/bosses/boss_horse_main.gd` — `_cast_grey_skill()` 中加冲刺音效
- `system/levels/world3/bosses/boss_horse_minor.gd` — `_cast_grey_dash_skill()` 中加冲刺音效
- `system/scene/title_screen.gd` — `mouse_entered` + 三个 `_on_*_pressed` 回调中加音效

### 可能需要追加判断逻辑的文件（1 个）

- `system/levels/world3/props/bomb_red_horse.gd` — 红马哑火条件判定（需先确认产品逻辑）

### 需同步更新的文档（1 个）

- `Docs/资源调用索引.md` — SFX 章节标注新增的 6 个映射
