### 召唤商鞅 CD 计算
```
summon_cooldown = 12.0s（@export）
can_summon = true（初始）

F 按下 → can_summon_shangyang_now() 校验：
  ① enable_input_control
  ② shangyang_summon_unlocked
  ③ active_summon_item 存在 且 item_type == SUMMON_BOOK 且 id == "summon_shangyang"
  ④ can_summon == true
  ⑤ 无已存在的 shangyang_player_summon 节点

通过 → try_summon_shangyang():
  can_summon = false
  summon_cooldown_timer = summon_cooldown（12.0）
  → SUMMON_START → play("draw") + play sound
  → 0.2s 后 execute_summon() 实例化商鞅
  → draw 动画结束 → SUMMON_END → 回到正常状态

每帧 handle_common_updates(delta):
  if summon_cooldown_timer > 0: timer -= delta → <= 0 时 can_summon = true

get_summon_cooldown_ratio():
  return (summon_cooldown - summon_cooldown_timer) / summon_cooldown  → 0.0→1.0
```

### World3 马的碰撞机制

- 红马炸弹：`Area2D`，`layer=64, mask=2`，boom 时检测 → `player.take_damage(10.0)`

func _apply_zhong_effect(item: InventoryItem) -> void:

### 任务 4：使用动画流程改造

**当前问题**：CONSUMABLE 类型使用时走 `PlayerInventory.use_item()` → 直接扣数量 → 发 `item_used` 信号 → 立即执行效果。没有播放 draw 动画。

**改造方案**：

在 `Player._on_inventory_item_used()` 中，对于需要 draw 动画的物品（通过 `item.use_animation != ""` 判断）：

1. 先进入 `SUMMON_START` 状态播放 draw 动画
2. draw 动画结束后再执行效果逻辑
3. 使用一个待处理队列 `_pending_item_effect: InventoryItem` 保存待执行的效果

```gdscript
var _pending_item_effect: InventoryItem = null

func _on_inventory_item_used(item: InventoryItem) -> void:
    if item == null:
        return
    if not item.use_animation.is_empty():
        _pending_item_effect = item
        change_state(PlayerState.SUMMON_START)
        return
    _execute_item_effect(item)

func _execute_item_effect(item: InventoryItem) -> void:
    match item.id:
        &"potion_health":
            if stats != null: stats.health += 1
        &"summon_zhong":
            _zhong_active = true
            _zhong_timer = item.effect_duration if item.effect_duration > 0 else 8.0
            _spawn_pixel_text_at_front("重")
        &"summon_hui":
            if stats != null: stats.health += int(item.effect_value) if item.effect_value > 0 else 4
            _spawn_pixel_text_at_front("恢")
```

在 `_on_animation_finished` 的 `SUMMON_START` 分支中，补充处理待执行效果：
```gdscript
PlayerState.SUMMON_START:
    if anim_name == "draw":
        if _pending_item_effect != null:
            _execute_item_effect(_pending_item_effect)
            _pending_item_effect = null
        change_state(PlayerState.SUMMON_END)
```

### 任务 6：使用后 CD bar 显示

**当前状态**：召唤商鞅的 CD bar 在 HUD 左侧（`SummonSkill/CooldownBar`），每帧读取 `Player.get_summon_cooldown_ratio()`。

**需求变更**：消耗品（重/恢）使用后也需要 CD bar 反馈。

**方案**：在 Player 中新增消耗品使用冷却：
```gdscript
var consumable_cooldown_timer: float = 0.0
var consumable_cooldown_duration: float = 1.5  # 消耗品公共 CD

func get_consumable_cooldown_ratio() -> float:
    if consumable_cooldown_duration <= 0.001:
        return 0.0
    return clampf((consumable_cooldown_duration - consumable_cooldown_timer) / consumable_cooldown_duration, 0.0, 1.0)
```

在 `handle_common_updates` 中递减。在快捷栏格子 UI 上增加一个覆盖式 CD bar（`ColorRect` 或 `TextureProgressBar`），显示消耗品公共 CD 进度。
