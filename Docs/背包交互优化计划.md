# 背包交互优化计划

## 概述

对背包 UI 的交互逻辑进行全面优化，涉及点击/拖拽/双击/右键等操作。

---

## 步骤 1：分离"选择"与"拖拽"

**目标**  
鼠标左键点击格子时只切换选中状态，不启动拖拽；只有按住左键并移动鼠标时才进入拖拽模式。

**改动范围**  
`inventory_ui.gd` — `_on_item_slot_gui()`、`_on_grid_panel_gui()`、`_input()`、`_finish_grid_drag()`

**实现方式**  
- 左键按下时只记录 `_selected_slot`，标记"可能拖拽"状态，不创建预览
- 在 `_input()` 中检测鼠标移动 + 按钮按下 → 进入拖拽模式，创建 `_drag_preview`
- 松开左键时如果处于拖拽模式则 `_finish_grid_drag()`，否则只视为点击选择

**验收标准**  
- 点击格子：只高亮选中，不产生拖拽
- 按住左键拖动：出现拖拽预览，松手后物品交换到目标格子
- 点击空白格：切换选中到该格

---

## 步骤 2：双击使用道具

**目标**  
鼠标双击任意格子时执行"使用"操作（等价于点击"使用"按钮）。

**改动范围**  
`inventory_ui.gd` — 新增局部变量 `_last_click_time`，在 `_on_item_slot_gui()`、`_on_grid_panel_gui()` 中检测双击

**实现方式**  
- 记录 `_last_click_slot` 和 `_last_click_time`
- 同一格子两次点击间隔 < 300ms 时调用 `_apply_use()`

**验收标准**  
- 双击有道具的格子 → 使用道具（消耗品扣除/召唤书装备）
- 双击空格子 → 无反应
- 双击不同格子 → 视为两次单击，不触发使用

---

## 步骤 3：隐藏"使用/丢弃/卸下召唤"按钮，改为右键弹出菜单

**目标**  
移除底部 `BtnRow`（使用/丢弃/卸下召唤按钮），改为鼠标右键点击格子时在鼠标位置弹出操作菜单（包含"使用""丢弃""卸下召唤"三个选项）。

**改动范围**  
- `inventory_ui.tscn` — 移除 `PanelActions` 及其子节点
- `inventory_ui.gd` — 新增 `_context_menu` 动态创建函数；`_on_item_slot_gui()`、`_on_grid_panel_gui()` 中检测右键

**实现方式**  
- 新增 `_show_context_menu(slot_index: int, screen_pos: Vector2)` 创建包含三个按钮的 PanelContainer
- 按钮的文字/可用状态与当前 `_hotbar_detail()` 逻辑一致
- 点击菜单外任意位置关闭菜单

**验收标准**  
- 右键有物品的格子 → 在鼠标位置弹出菜单（"使用"/"丢弃"/"卸下召唤"）
- 右键空格子 → 不弹出
- 左键点击菜单外的区域 → 菜单关闭
- "丢弃"点击后有确认弹窗

---

## 步骤 4：拖拽预览缩小为 4/5

**目标**  
拖拽物品时，预览面板缩小为原尺寸的 4/5，并对准鼠标指针中心。

**改动范围**  
`inventory_ui.gd` — `_create_drag_preview()`

**实现方式**  
- 设置 `drag_preview.scale = Vector2(0.8, 0.8)`（即 4/5）
- 调整 `global_position` 使预览中心对齐鼠标指针（减去一半缩小后的尺寸）

**验收标准**  
- 拖拽物品时预览明显小于格子大小（约为原 64% 面积）
- 预览中心对准鼠标指针
- 松手后预览消失

---

## 步骤 5：放下物品后，目标格变为待选状态

**目标**  
完成拖拽放下后，目标格子自动成为当前选中格（高亮）。

**改动范围**  
`inventory_ui.gd` — `_finish_grid_drag()`

**实现方式**  
- 在 `_finish_grid_drag()` 确定 `target_gi` 后，将 `_selected_slot` 设为 `target_gi`
- 调用 `_refresh_selection_and_detail()`

**验收标准**  
- 拖拽物品到新格子放下 → 目标格立即高亮选中
- 选中格在详情面板显示对应的物品信息

---

## 步骤 6：移除 .tscn 中废弃的按钮面板节点

**目标**  
从 `inventory_ui.tscn` 中删除 `PanelActions` 及其子节点（BtnRow、BtnUse、BtnDrop、BtnUnequipSummon），清理引用。

**改动范围**  
`inventory_ui.tscn` — 删除以下节点及其子节点：
- `PanelActions`
- `BtnRow`
- `BtnUse`
- `BtnDrop`
- `BtnUnequipSummon`

同时删除对应的 `@onready` 变量（`_btn_use`、`_btn_drop`、`_btn_unequip`）和 `pressed` 信号连接。

**验收标准**  
- 背包打开时底部不显示任何按钮
- 脚本无引用断连错误
